# 🛒 E-Commerce SQL Analysis Project

## 📌 Project Overview
This project analyzes an e-commerce database using SQL to extract business insights like revenue trends, customer behavior, and product performance.

## 🧱 Database Schema
- Customers
- Orders
- Products
- Order Items

## 📊 Key Insights Queries
- Total Revenue Calculation
- Top Customers by Spending
- Monthly Revenue Trends
- Best Selling Products
- Customer Lifetime Value
- Repeat Customers Analysis

## 🛠️ Tools Used
- SQL (SQLite)
- GitHub

## 🚀 Project Files
- schema.sql → Database structure
- queries.sql → Business analysis queries

## 🎯 Outcome
Developed strong SQL skills including:
- Joins
- Aggregations
- Group By & Having
- Subqueries
- Real-world business problem solving
